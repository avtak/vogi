# Demo video script (3 minutes)

Record the screen at 1280 × 800 or larger, with the browser zoom at 125 %. Speak slowly.
Use the real model (`muse-spark-1.3`), never the fake host.

| Time | Screen | Say |
|---|---|---|
| 0:00–0:20 | The empty Vogi page | "I learn German in Leipzig. When I ask a chatbot to correct my German, it rewrites everything, and I learn nothing. Or I must write a long prompt first. Vogi needs no prompt." |
| 0:20–0:50 | Type `Gestern ich habe mit mein Bruder Fußball gespielt.` Pick A2 and Grammar only. Click Check | "I pick my level and what I want: grammar only. Vogi changes only the errors. Each change has a category and the rule, at my level." |
| 0:50–1:10 | Point at the grey box "Vogi checked its own answer" | "Before I see the answer, Vogi checks it with code: every change must point at words that are really in my text." |
| 1:10–1:30 | Same text, pick Sound natural, Check | "Same text, another goal. Now Vogi also makes it sound natural. The format stays the same, so the app can show it, and later my other app can use it." |
| 1:30–2:05 | Photo tab. Upload the photo of the handwritten text. Fix one misread word. Click "This is what I wrote" | "Most learners write homework by hand. Muse Spark reads my handwriting and copies it with my mistakes. It does not correct yet. I fix what it misread, and I confirm." |
| 2:05–2:30 | Click Practise my mistakes. Answer one exercise right and one wrong | "Now Vogi writes three new exercises from my own mistakes, and it checks my answers." |
| 2:30–2:50 | Scroll to "How good is Vogi?" and the score table | "Is it any good? I wrote a test set of 38 sentences with known errors. Vogi scores each model on it: errors fixed, and correct sentences left alone. The same code runs on Muse Spark 1.3 and on the open-weight Muse Spark Open." |
| 2:50–3:00 | The repo README | "Everything here was built during the hackathon. Vogi: German writing you can learn from." |

If Muse Spark Open has no key by the recording day, cut "and on the open-weight Muse Spark Open" and show one row.

## Text for the handwritten photo

Write these three sentences by hand on paper, with the mistakes, and photograph them in daylight:

> Gestern ich habe mit mein Bruder Fußball gespielt. Danach wir sind in ein Café gegangen.
> Ich habe ein Kuchen gegessen, weil ich hatte Hunger.

The five mistakes: verb position after *Gestern* and after *Danach*, dative after *mit*,
accusative *einen Kuchen*, and the verb at the end after *weil*.
